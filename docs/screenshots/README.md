# Screenshots

App UI captures used by the root README, taken on the Android emulator with
the r18 build (es-ES, 2026-10-01; status bar cropped, no metadata). The three
current files are pure interface (colour blocks and controls) — no faces, no
personal photos; the analysed inputs were the repo's synthetic samples
(`samples/test_outfit.png`, `samples/product-synth/prod-01-red-on-white.jpg`).

- `01.png` — split Home ("Mi pikete" on top, "Mis zapas" below — the order
  since r17)
- `02.png` — outfit result, recommendation-first ("Toma tu pikete" hero combo
  + the "Tu fit" strip; the synthetic figure is read as a whole photo, so no
  ARRIBA/ABAJO rows and no "Vérmelo puesto" button)
- `03.png` — sneaker result (colour combination for the shoes, "Súbela a tu
  story"); a long screenshot stitched from two scroll positions
- `04.png` — "Vérmelo puesto" before/after: the original photo (left) and the
  r19 recolor screen with ABAJO (the shorts) recolored to the recommended
  "verde-azulado" (right), both scaled to the same height. The photo is a
  **licensed Pexels stock photo** (Vika Glitter, ID 17091660, Pexels License;
  credit in the overlay `ATTRIBUTION.md`), EXIF stripped; the stock file itself
  is not in the repo. Public repo rule: licensed stock only, never the
  founder's own photo.
